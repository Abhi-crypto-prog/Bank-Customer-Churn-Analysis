# Bank Customer Churn Analysis | Power BI Executive Dashboard

## 📌 Project Overview
This project focuses on building an end-to-end Data Analytics solution for a banking institution experiencing a high customer churn rate (**22.15%**). Using Power BI and Power Query, the raw customer transaction logs were cleaned, modeled, and transformed into an interactive Executive Dashboard that delivers actionable insights to reduce attrition and optimize customer retention strategies.
